# Star Labs - TechJam 2026 Track 4 - submission requirements

# The scoring path has NO third-party dependencies. The agent is pure Python
# standard library: json, math, re, difflib, collections, pathlib.
# There is nothing to pip install.
#
# It makes NO network calls and needs NO API credentials, so it runs unchanged
# under the organizer's network-disabled scoring policy (docs/submission_rules.md).
# Reported token usage is zero.
#
# Python: requires >= 3.10 (PEP 604 annotations). Verified on CPython 3.11.12.
#
# One command, from the repo root with data/catalog.jsonl in place:
#     python3 -m evaluator.local_evaluator
# Expected on the public 200: TechnicalScore 0.9800 (hit@10 1.000, MRR 1.0000).
#
# Optional (OFF by default, not used for scoring): setting the environment
# variable TECHJAM_DENSE=1 enables a dense-retrieval escalation lane and then
# requires:  sentence-transformers>=3.0  (plus its torch dependency).
# It fires only when a constraint resolves nowhere in the exact index; the
# clean score is byte-identical either way (0.9800) and any import/weight/
# network failure falls back silently to the stdlib cascade.
